```markdown
# React File List Challenge (Desafío de lista de archivos en React)

Una nueva característica llamada **Server Components** llegará a producción la próxima semana. Para la presentación principal (*keynote*), alguien creó una animación de 10 segundos que resume muy bien esta funcionalidad, mostrando un árbol de componentes con diferentes colores para distinguir los **Client Components** de los **Server Components**.

Nuestro cliente, **Molecule Text Editor**, te asignó al equipo encargado de **Sidebar > Files**. Quieren implementar un componente que muestre un árbol de archivos, donde los archivos con extensión `*.server` y `*.client` tengan colores diferentes y se respete la indentación correspondiente a cada nivel del árbol.

En el proyecto dejaron dos archivos de ejemplo:

- `data-nested.json`
- `data-plain.json`

Puedes elegir la estructura de datos que prefieras. Como buenos *backend developers*, te dijeron que ellos refactorizarán su parte del proyecto según la decisión que tomes.

## Tareas

- [ ] Mostrar todas las carpetas y archivos utilizando elementos `ul` y `li`.
- [ ] Los archivos y carpetas deben tener la indentación correcta según su nivel de profundidad en el árbol.
- [ ] Las carpetas deben poder expandirse y contraerse para mostrar u ocultar su contenido.
- [ ] Los archivos `*.server` y `*.client` deben mostrarse con colores diferentes al resto de los archivos.
```
